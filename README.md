# KENES — монитор корпоративного управления

Портал о корпоративном управлении в Казахстане и Центральной Азии: назначения в советы директоров, квазисектор, законы, карта регионов, институты КУ, события, обучение.

Сайт закрыт паролем: содержимое `index.html` зашифровано (AES-256-GCM, ключ из пароля через PBKDF2), без пароля в репозитории виден только экран входа.
